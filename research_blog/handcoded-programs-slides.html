Hand-Coded Process and Outcome Programs

1 · The task and the two losses

Same prompt, two continuations

Count the query letter modulo \(m\): \(s_t = (s_{t-1} + [w_t = q]) \bmod m\). Each letter either keeps the state or adds one. Running example: \(A = 4\) letters, \(m = 3\), \(n = 6\).

\[ \mathcal{L}_{\mathrm{proc}} = -\sum_{t=1}^{n} \log p_\theta(s_t \mid \text{prompt}, s_{\lt t}) + \ell_{\mathrm{tail}}, \qquad \mathcal{L}_{\mathrm{out}} = \ell_{\mathrm{tail}} = -\log p_\theta({:}\ s_n\ \mathrm{EOS} \mid \text{prompt}) \]
  • Both programs on the next slides are exact weight settings of the same tensors. Every figure is computed live from those weights in this page; slide 8 lets you change the word.

2 · One architecture

Two blocks, three heads, no LayerNorm

\(X^{(0)} = E_{\mathrm{tok}}[\mathrm{ids}] + E_{\mathrm{pos}}[0{:}T]\)\(T \times W\)
\(S_h = (X W^{Q\top}_h)(X W^{K\top}_h)^{\top} / \sqrt{P} + M\)\((T{\times}P)(P{\times}T)\)
\(X \mathrel{+}= \sum_{h=1}^{3} \mathrm{softmax}(S_h)\, X W^{V\top}_h\)\((T{\times}T)(T{\times}W)\)
\(X \mathrel{+}= \mathrm{ReLU}(X W_{\mathrm{in}}^{\top} + b)\, W_{\mathrm{out}}^{\top}\)\((T{\times}F)(F{\times}W)\)
\(\mathrm{logits} = X R^{\top}\) after blocks \(\ell = 0, 1\)\(T \times |\mathcal V|\)

\(M\) is the causal mask (\(-\infty\) above the diagonal). The query and key width is \(P\), the number of positions, so a head can address any row.

3 · Block encoding of the residual stream

Every coordinate has a name

\[ E_{\mathrm{tok}}[a, \mathrm{TL}_a] = 1, \quad E_{\mathrm{tok}}[A{+}v, \mathrm{TV}_v] = 1, \quad E_{\mathrm{pos}}[i, \mathrm{POS}_i] = 1 \]
\[ W = \underbrace{A + m + P}_{\text{embeddings}} + \underbrace{A + 1}_{\text{block 0}} + \underbrace{m + 1}_{\text{process}} + \underbrace{1 + m}_{\text{outcome}} + \underbrace{m}_{\mathrm{OUT}} = 2A + 4m + 2n + 9 = 41 \]
  • Every weight is a block matrix between named slots, e.g. \(W^{V}[\mathrm{dst}, \mathrm{src}] = I\). Readout: \(R[A{+}v, \mathrm{OUT}_v] = 20\).

4 · The one attention trick

A routing head is a position lookup

\(W^{K}_h[:, \mathrm{POS}] = I_P \;\Rightarrow\; k_j = e_j \in \mathbb{R}^{P}\)
\(W^{Q}_h[\mathrm{tgt}(i), \mathrm{POS}_i] = C \;\Rightarrow\; q_i = C\, e_{\mathrm{tgt}(i)}\)
\(\dfrac{q_i^{\top} k_j}{\sqrt{P}} = \mathrm{GAP} \cdot \mathbb{1}[j = \mathrm{tgt}(i)], \quad C = \mathrm{GAP}\sqrt{P}\)
\(\text{leak} \le (T{-}1)\, e^{-\mathrm{GAP}} \le \dfrac{2(n+3)}{(8(n+3))^{3}}\)
  • \(\mathrm{GAP} = \max\{16,\ 3 \log 8(n{+}3)\}\), so the softmax is one-hot up to \(e^{-16} \approx 10^{-7}\) for every \(n\).
  • \(W^{V}_h\) then copies one slot into another, e.g. \(W^{V}_0[\mathrm{QRY}, \mathrm{TL}] = I_A\). A list of targets gives a uniform average.

5 · Block 0, shared by both programs

Mark every letter that equals the query

\[ x_{\mathrm{QRY}} \leftarrow x_{\mathrm{TL}}^{(\text{row } 1)} = e_q, \qquad x_{\mathrm{MATCH}} \mathrel{+}= 2\sum_{a=1}^{A} \mathrm{ReLU}\big(x_{\mathrm{TL}_a} + x_{\mathrm{QRY}_a} - 1.5\big) = [w_t = q] \]
  • Uses \(A\) of the \(F\) hidden units: row \(a\) of \(W_{\mathrm{in}} \in \mathbb{R}^{F \times W}\) has two 1s (at \(\mathrm{TL}_a, \mathrm{QRY}_a\)), \(b_a = -1.5\), and \(W_{\mathrm{out}}[\mathrm{MATCH}, a] = 2\).

6 · Block 1, process program

One update per emitted state

\[ u^{0}_j = \mathrm{ReLU}(x_{\mathrm{PREV}_j} - x_{\mathrm{MT}} - \tfrac12) \to \mathrm{OUT}_j, \;\; u^{1}_j = \mathrm{ReLU}(x_{\mathrm{PREV}_j} + x_{\mathrm{MT}} - \tfrac32) \to \mathrm{OUT}_{(j+1) \bmod m} \]
  • Exactly one of the \(2m\) units fires, at \(0.5\), and \(W_{\mathrm{out}} = 2\) makes \(x_{\mathrm{OUT}} = e_{s_t}\). Each emitted state needs one mark and one previous value.

7 · Block 1, outcome program

Read all \(n\) marks at the colon

\[ x_{\mathrm{CNT}} = n \cdot \tfrac{1}{n}\textstyle\sum_t [w_t = q] = c, \quad \beta_{c'}(x) = r(x{-}c'{+}1) - 2r(x{-}c') + r(x{-}c'{-}1) = \mathbb{1}[x = c'] \]
  • Unit input \(x = x_{\mathrm{CNT}} + (n{+}2)(x_{\mathrm{S0}_j} - 1)\): groups with \(j \ne s_0\) sit below \(-1\) and stay off. All \(3m(n{+}1) = 63\) units are used.
