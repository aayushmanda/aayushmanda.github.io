Hand-Coded Process and Outcome Programs

Process vs outcome supervision

Two hand-written programs, one Transformer

Letter counting: we write the exact weights for a step-by-step solution and an all-at-once solution, in the same 2-block architecture.

Running example on every slide: \(s_0 = 1,\ q = \mathtt{a},\ \text{word} = \mathtt{b\,a\,d\,a\,c\,a}\). Every figure is computed live from the weights.

1 · Task

Count the query letter, mod \(m\)

Example \(m = 3\): start at \(s_0 = 1\), add 1 at every a in b a d a c a. States: \(1, 2, 2, 0, 0, 1\). Answer \(s_6 = 1\).
In general \(s_t = (s_{t-1} + [w_t = q]) \bmod m\). Process trains on \(s_1, \dots, s_n\) and the answer; outcome trains on the answer only:
\[ \mathcal{L}_{\mathrm{proc}} = -\sum_{t=1}^{n} \log p_\theta(s_t \mid \text{prompt}, s_{\lt t}) + \ell_{\mathrm{ans}}, \qquad \mathcal{L}_{\mathrm{out}} = \ell_{\mathrm{ans}} = -\log p_\theta({:}\ s_n\ \mathrm{EOS} \mid \text{prompt}) \]
  • Same architecture for both. We write one exact weight setting for each: \(\theta_{\mathrm{proc}}\) and \(\theta_{\mathrm{out}}\).

3 · Architecture

A plain 2-block Transformer

\(X = E_{\mathrm{tok}}[\mathrm{ids}] + E_{\mathrm{pos}}[0{:}T]\)\(T \times W\)

4 · Residual stream

Each quantity gets its own named slot

Example At the letter a: TL holds \(e_{\mathtt a}\), block 0 writes QRY \(= e_{\mathtt a}\) and MATCH \(= 1\). Click a slot to see who writes and reads it.
In general \(W = \underbrace{A + m + P}_{\text{embeddings}} + \underbrace{A + 1}_{\text{block 0}} + \underbrace{m + 1}_{\text{process}} + \underbrace{1 + m}_{\text{outcome}} + \underbrace{m}_{\mathrm{OUT}} = 2A + 4m + 2n + 9\)
  • So every weight is a copy from one slot to another, e.g. \(W^{V}[\mathrm{dst}, \mathrm{src}] = I\). Readout: \(R[A{+}v, \mathrm{OUT}_v] = 20\).

5 · Attention

Each head looks up one position

Example Proc h1: each state row (8–13) reads its own letter \(w_t\) (rows 2–7), a diagonal. Other rows fall back to row 0. Click the buttons for the other heads.
Keys: \(k_j = e_j\) (position one-hot)
Query at \(i\): \(q_i = C\, e_{\mathrm{tgt}(i)}\)
Score \(= \mathrm{GAP}\) on the target, \(0\) elsewhere
  • \(\mathrm{GAP} = 16\) here: weight off the target \(\le (T{-}1)\,e^{-16} \lt 10^{-5}\)
  • Value copies a slot, e.g. \(W^{V}_0[\mathrm{QRY}, \mathrm{TL}] = I\)
  • Several targets give a uniform average

6 · Block 0 (shared by both)

Mark each letter: is it \(q\)?

Example b a d a c a \(\to\) marks 0 1 0 1 0 1.
In general Head 0 copies \(q\) into QRY; the MLP writes \(\mathrm{MATCH} = 2\sum_a \mathrm{ReLU}(x_{\mathrm{TL}_a} + x_{\mathrm{QRY}_a} - \tfrac32) = [w_t = q]\).

7 · Block 0 · inside the MLP

One unit per letter, an AND gate

Example At \(w_2 = \mathtt a\): unit \(\mathtt a\) gets \(1 + 1 - 1.5 = 0.5\), times 2 gives MATCH \(= 1\). At \(w_1 = \mathtt b\): unit \(\mathtt b\) gets \(1 + 0 - 1.5 \lt 0\), so 0.
\[ \begin{array}{c|cc} W_{\mathrm{in}} & \mathrm{TL}_a & \mathrm{QRY}_a \\ \hline u_a & 1 & 1 \end{array} \qquad \begin{array}{c} b \\ \hline -\tfrac32 \end{array} \qquad \begin{array}{c|c} W_{\mathrm{out}}^{\top} & \mathrm{MATCH} \\ \hline u_a & 2 \end{array} \qquad a = 1, \dots, A \]

8 · Process · block 1

Each step: last state + one mark

Example \(t = 4\): previous state \(s_3 = 2\), mark of \(w_4 = \mathtt a\) is 1, so \(s_4 = (2 + 1) \bmod 3 = 0\). Step through \(t\) below.
In general Head 0 brings \(s_{t-1}\) (PREV), head 1 brings \([w_t = q]\) (MT); \(2m\) MLP units compute \(s_t\). The work per step does not depend on \(n\).

9 · Process · inside the MLP

Two units per state value

Example \(\mathrm{PREV} = e_2,\ \mathrm{MT} = 1\): unit \(u^1_2 = \mathrm{ReLU}(1 + 1 - 1.5) = 0.5\) fires and writes \(\mathrm{OUT}_{0}\). All others are \(\le 0\).
\[ \underbrace{u^{0}_j = \mathrm{ReLU}(x_{\mathrm{PREV}_j} - x_{\mathrm{MT}} - \tfrac12)}_{\text{no match: stay at } j} \to \mathrm{OUT}_j, \qquad \underbrace{u^{1}_j = \mathrm{ReLU}(x_{\mathrm{PREV}_j} + x_{\mathrm{MT}} - \tfrac32)}_{\text{match: move to } j+1} \to \mathrm{OUT}_{(j+1) \bmod m} \]

10 · Outcome · block 1

One position reads all \(n\) marks at once

Example At ':', head 0 averages the marks 0 1 0 1 0 1 \(\to \tfrac36\), times 6 gives count \(c = 3\). Head 1 reads \(s_0 = 1\). Answer \((1 + 3) \bmod 3 = 1\).
In general The MLP needs one detector for every pair \((s_0, c)\), \(c = 0, \dots, n\): that is \(3m(n{+}1)\) units, growing with \(n\).

11 · Outcome · inside the MLP

A bump detector for each count

Example \(c = 3\): the bump for \(c' = 3\) gives \(r(1) - 2r(0) + r(-1) = 1\). The bump for \(c' = 2\) gives \(r(2) - 2r(1) + r(0) = 0\).
\[ \beta_{c'}(x) = r(x{-}c'{+}1) - 2\,r(x{-}c') + r(x{-}c'{-}1) = \mathbb{1}[x = c'] \quad \text{for integer } x, \qquad r = \mathrm{ReLU} \]
