Hand-Coded Process and Outcome Programs

1 · The task and the two losses

Same prompt, two continuations

Count the query letter modulo \(m\): \(s_t = (s_{t-1} + [w_t = q]) \bmod m\). Running example: \(A = 4\), \(m = 3\), \(n = 6\), \(s_0 = 1\), \(q = \texttt{a}\), word \(\texttt{b a d a c a}\).

  • Orange tokens carry the loss. Process supervises \(s_1, \dots, s_n\) and the answer. Outcome supervises only the answer.
  • Both exact programs are weights of one architecture. Everything is scored by greedy free-running generation.

2 · One architecture

Two blocks, three heads, no LayerNorm

\[ \begin{aligned} X^{(0)} &= E_{\mathrm{tok}}[\mathrm{ids}] + E_{\mathrm{pos}}[0{:}T] \in \mathbb{R}^{T \times W}, \qquad Q_h = X W^{Q\top}_h,\ K_h = X W^{K\top}_h \in \mathbb{R}^{T \times P} \\ X &\leftarrow X + \textstyle\sum_{h=1}^{3} \mathrm{softmax}\big(Q_h K_h^{\top}/\sqrt{P} + M\big)\, X W^{V\top}_h \qquad X \leftarrow X + \mathrm{ReLU}(X W_{\mathrm{in}}^{\top} + b)\, W_{\mathrm{out}}^{\top} \end{aligned} \]

\(|\mathcal V| = A + m + 3\) (letters, values, SEP, :, EOS). \(P = 2n + 6\) is the longest row and the head width. \(F = \max\{A,\ 3m(n+1),\ 2n+1\}\). Logits are \(X R^{\top} \in \mathbb{R}^{T \times |\mathcal V|}\).

3 · Block encoding of the residual stream

Every coordinate has a name

\[ E_{\mathrm{tok}}[a, \mathrm{TL}_a] = 1, \quad E_{\mathrm{tok}}[A{+}v, \mathrm{TV}_v] = 1, \quad E_{\mathrm{pos}}[i, \mathrm{POS}_i] = 1, \qquad R[A{+}v, \mathrm{OUT}_v] = 20 \]
  • Each slot holds a one-hot or one scalar, so every weight below is a small block of 0s and \(\pm 1\)s between named slots.
  • The readout also puts 20 on \(R[{:}, \mathrm{POS}_i]\) and \(R[\mathrm{EOS}, \mathrm{POS}_j]\) at the two rows that must emit those tokens.

4 · The one attention trick

A routing head is a position lookup

\[ W^{K}_h[:, \mathrm{POS}] = I_P, \quad W^{Q}_h[\mathrm{tgt}(i), \mathrm{POS}_i] = C = \mathrm{GAP}\sqrt{P} \ \Longrightarrow\ \tfrac{q_i^{\top} k_j}{\sqrt P} = \mathrm{GAP}\cdot \mathbb{1}[j = \mathrm{tgt}(i)] \]
  • \(\mathrm{GAP} = \max\{16,\ 3\log 8(n+3)\}\), so any other position gets weight at most \(e^{-16} \approx 10^{-7}\). A list of targets gives a uniform average.
  • The value matrix copies one slot into another, for example \(W^{V}_0[\mathrm{QRY}, \mathrm{TL}] = I_A\). Rows without a target attend to a harmless default row.

5 · Block 0, shared by both programs

Mark every letter that equals the query

\[ x_{\mathrm{QRY}} \leftarrow e_q \ \text{(head 0)}, \qquad x_{\mathrm{MATCH}} \mathrel{+}= 2\sum_{a=1}^{A} \mathrm{ReLU}\big(x_{\mathrm{TL}_a} + x_{\mathrm{QRY}_a} - 1.5\big) = [w_t = q] \]
  • Uses \(A\) of the \(F\) hidden units: \(W_{\mathrm{in}}\) is \(A \times W\) with two 1s per row, \(b = -1.5\), and \(W_{\mathrm{out}}\) writes 2 into the single MATCH coordinate.

6 · Block 1, process program

One update per emitted state

\[ u^{0}_j = \mathrm{ReLU}(x_{\mathrm{PREV}_j} - x_{\mathrm{MT}} - 0.5) \to \mathrm{OUT}_j, \; u^{1}_j = \mathrm{ReLU}(x_{\mathrm{PREV}_j} + x_{\mathrm{MT}} - 1.5) \to \mathrm{OUT}_{j+1 \bmod m} \]
  • Row \(n{+}1{+}t\) adds its own value \(s_{t-1}\) to the mark of \(w_t\). For \(t = 1\) that row is SEP, which reads \(s_0\) at row 0.
  • \(2m\) units, here 6 of 63. Head 2 copies \(s_n\) after the colon.

7 · Block 1, outcome program

Read all \(n\) marks at the colon

\[ x_{\mathrm{CNT}} = n \cdot \tfrac{1}{n}\textstyle\sum_t b_t = c, \quad \beta_{c'}(x) = r(x{-}c'{+}1) - 2r(x{-}c') + r(x{-}c'{-}1) = \mathbb{1}[x = c'] \]
  • One bump per pair \((s_0 = j,\ c')\), gated by \((n+2)(x_{\mathrm{S0}_j} - 1)\), writes \(\mathrm{OUT}_{(j + c') \bmod m}\). That is \(3m(n+1)\) units, here all 63.
  • Same tensors as slide 6: block 0 is identical, and the process program leaves these units at zero. Process needs \(2m\) units, outcome \(3m(n+1)\).
