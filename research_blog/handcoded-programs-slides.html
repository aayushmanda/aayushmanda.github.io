Hand-Coded Process and Outcome Programs

Process vs outcome supervision

Two hand-written programs, one Transformer

Letter counting: we write the exact weights for a step-by-step solution and an all-at-once solution, in the same small network.

Running example on every slide: \(s_0 = 1,\ q = \mathtt{a},\ \text{word} = \mathtt{b\,a\,d\,a\,c\,a}\). Only basic linear algebra is needed. Every figure is computed live from the weights.

1 · Task

Count the query letter, mod \(m\)

Example \(m = 3\): start at \(s_0 = 1\) and add 1 at every a in b a d a c a, wrapping around at 3. The answer is \(s_6 = 1\).
step \(t\)0123456
letter \(w_t\)badaca
mark: is it a?010101
state \(s_t\)1122001
In general \(s_t = (s_{t-1} + [w_t = q]) \bmod m\), where \([w_t = q]\) is 1 if the letter equals the query and 0 otherwise.
  • Process supervision: the model is trained to write every state \(s_1, \dots, s_6\), then the answer.
  • Outcome supervision: the model is trained to write only the answer \(s_6\).

2 · The two programs in words

Step by step vs all at once

  • Process (top row): write \(1, 2, 2, 0, 0, 1\). Each new state needs only the previous state and one mark: \(s_4 = (2 + 1) \bmod 3 = 0\).
  • Outcome (bottom row): write only the answer. It must count all the marks at once: \(c = 3\), so \((1 + 3) \bmod 3 = 1\).
  • Both get the same prompt and the same network. We write the exact weights for each by hand.

3 · Toolkit

Three facts from linear algebra

Every weight in this deck is built from these three facts.

1. One-hot vectors. Letter c of a, b, c, d is \(e_{\mathtt c} = (0, 0, 1, 0)\). Dot products test equality: \(e_i \cdot e_j = [i = j]\), i.e. 1 if equal and 0 if not.

2. ReLU makes an AND gate. \(\mathrm{ReLU}(x) = \max(0, x)\). For bits \(x, y \in \{0, 1\}\):

\[ 2\,\mathrm{ReLU}(x + y - 1.5) = \begin{cases} 2 \cdot 0.5 = 1 & x = y = 1 \\ 0 & \text{otherwise (the sum is } \le -0.5) \end{cases} \]

3. Softmax with one big score picks one entry. \(\mathrm{softmax}(z)_j = e^{z_j} / \sum_k e^{z_k}\):

\[ \mathrm{softmax}(16, 0, 0, 0) \approx (0.9999997,\ 10^{-7},\ 10^{-7},\ 10^{-7}), \qquad \mathrm{softmax}(16, 16, 0, 0) \approx (\tfrac12, \tfrac12, 0, 0) \]

One winner gives a lookup of one row. Several tied winners give their average.

5 · The network

A table of vectors, updated twice

Example The process row has \(T = 18\) tokens, so the state of the network is an \(18 \times 41\) matrix \(X\). Row \(i\) is the vector for token \(i\).
\(X = E_{\mathrm{tok}}[\mathrm{ids}] + E_{\mathrm{pos}}[0{:}T]\)start: which token + where
\(S_h = (X W^{Q\top}_h)(X W^{K\top}_h)^{\top} / \sqrt{P}\)how much row \(i\) wants row \(j\)
\(X \mathrel{+}= \sum_{h} \mathrm{softmax}(S_h)\, X W^{V\top}_h\)attention: copy from other rows
\(X \mathrel{+}= \mathrm{ReLU}(X W_{\mathrm{in}}^{\top} + b)\, W_{\mathrm{out}}^{\top}\)MLP: same function on each row
\(\mathrm{logits} = X R^{\top}\)readout: score each next token
  • Attention + MLP is one block. There are 2 blocks.
  • Each block has 3 heads, i.e. 3 independent copy operations \(h\).
  • A row may only read rows at or before it (causal mask).

6 · Inside each row

Each vector is split into named slots

Example The row for the letter a at position 3 starts as \(e_{\mathtt a}\) in TL and \(e_3\) in POS. Block 0 then writes \(e_{\mathtt a}\) into QRY and 1 into MATCH.
TLthe letter, one-hotPREVprevious state \(s_{t-1}\)
TVa state value, one-hotMTcopy of the mark (process)
POSthe position, one-hotCNTthe count \(c\) (outcome)
QRYcopy of the query \(q\)S0start state \(s_0\) (outcome)
MATCHthe mark \([w_t = q]\)OUTthe value to print
In general Every slot has a single job. Attention weights are identity blocks that copy one slot into another; the MLPs hold the small AND gates.

A2 · Block 0 (same for both)

Mark each letter: is it \(q\)?

Example Every letter copies the query a from row 1, then compares: b a d a c a \(\to\) marks 0 1 0 1 0 1.

A4 · Process · block 1

Each step: last state + one mark

Example \(t = 4\): head 0 fetches \(s_3 = 2\), head 1 fetches the mark of \(w_4 = \mathtt a\) (= 1). The MLP outputs \(s_4 = (2 + 1) \bmod 3 = 0\). Step through \(t\) below.
In general Two lookups (\(s_{t-1}\) and one mark), then \(2m\) ReLU units compute \(s_t\). The work per step is the same for any word length \(n\).

A6 · Outcome · block 1

One row reads all \(n\) marks at once

Example At ':', head 0 gives all six letters equal weight \(\tfrac16\) (fact 3, tied scores). The average mark is \(\tfrac36\); times 6 gives \(c = 3\). Head 1 fetches \(s_0 = 1\).
In general The MLP must turn \((s_0, c)\) into \((s_0 + c) \bmod m\). It keeps one detector for every pair, \(c = 0, \dots, n\): \(3m(n{+}1)\) units, growing with \(n\).

A7 · Outcome · inside the MLP

A spike detector for each count

Example \(c = 3\). Detector \(c' = 3\): \(r(1) - 2r(0) + r(-1) = 1\). Detector \(c' = 2\): \(r(2) - 2r(1) + r(0) = 2 - 2 + 0 = 0\). Here \(r = \mathrm{ReLU}\).
\[ \beta_{c'}(x) = r(x{-}c'{+}1) - 2\,r(x{-}c') + r(x{-}c'{-}1) = \begin{cases} 1 & x = c' \\ 0 & \text{any other whole number } x \end{cases} \]
