1 · Task

Same prompt, two continuations

  • \(s_t = (s_{t-1} + [w_t = q]) \bmod m, \quad A = 4,\ m = 3,\ n = 6\)
\[ \mathcal{L}_{\mathrm{proc}} = -\sum_{t=1}^{n} \log p_\theta(s_t \mid \text{prompt}, s_{\lt t}) + \ell_{\mathrm{tail}}, \qquad \mathcal{L}_{\mathrm{out}} = \ell_{\mathrm{tail}} = -\log p_\theta({:}\ s_n\ \mathrm{EOS} \mid \text{prompt}) \]
  • One architecture, two exact weight settings \(\theta_{\mathrm{proc}}, \theta_{\mathrm{out}}\)
  • All figures computed live from these weights

5 · Routing

Attention as position lookup

\(W^{K}_h[:, \mathrm{POS}] = I_P \;\Rightarrow\; k_j = e_j \in \mathbb{R}^{P}\)
\(W^{Q}_h[\mathrm{tgt}(i), \mathrm{POS}_i] = C \;\Rightarrow\; q_i = C\, e_{\mathrm{tgt}(i)}\)
\(\dfrac{q_i^{\top} k_j}{\sqrt{P}} = \mathrm{GAP} \cdot \mathbb{1}[j = \mathrm{tgt}(i)], \quad C = \mathrm{GAP}\sqrt{P}\)
\(\text{leak} \le (T{-}1)\, e^{-\mathrm{GAP}} \le \dfrac{2(n+3)}{(8(n+3))^{3}}\)
  • \(\mathrm{GAP} = \max\{16,\ 3 \log 8(n{+}3)\} \;\Rightarrow\; \text{weight off target} \le e^{-16} \approx 10^{-7}\)
  • Copy: \(W^{V}_0[\mathrm{QRY}, \mathrm{TL}] = I_A\)
  • Several targets \(\Rightarrow\) uniform average
