Preference learning does not learn the ranking

Chen, Malladi, Zhang, Chen, Zhang, Ranganath, and Cho.

The belief the paper starts from

Why do these algorithms work?

  • Rafailov et al.: the DPO update raises the relative log probability of the preferred response.
  • Zhao et al.: calibrate with a ranking loss, and keep a KL penalty back to the reference.
  • Conventional wisdom: if ranking accuracy goes up, generation gets better.

Definition 2.3

Ranking accuracy is one bit

\[ \mathcal{R}(x, y_w, y_l; \pi_\theta) = \begin{cases} 1 & \pi_\theta(y_w \mid x) \ge \pi_\theta(y_l \mid x) \\ 0 & \text{otherwise.} \end{cases} \]
  • \(y_w\) is the continuation the majority preferred.
  • On a dataset, \(\mathcal{R}\) is the fraction of pairs ranked the right way.
  • Reward accuracy scores \(\beta \log \pi / \pi_{\mathrm{ref}}\). We sample from \(\pi\), so the paper tracks \(\pi\) itself.

Informal theorem

You can score the optimum without training

Informal theorem

Given \(\pi_{\mathrm{ref}}\), \(\beta\), and the vote share \(\alpha\) for each prompt, the pairwise ranking accuracy of a perfect DPO or RLHF model is a closed form. That number is the idealized ranking accuracy.

  • The question “should training produce a high ranking?” does not need a training run.
  • It is a function of the reference and of how unanimous the raters were.

Theorem 3.1

Perfect optimization still copies the reference

\[ \frac{\pi^\star(y_w \mid x)}{\pi^\star(y_l \mid x)} = \frac{\pi_{\mathrm{ref}}(y_w \mid x)}{\pi_{\mathrm{ref}}(y_l \mid x)} \left( \frac{\alpha}{1-\alpha} \right)^{1/\beta}. \]

Intuition

  • Bradley-Terry turns a reward gap into a preference probability.
  • The optimal KL-regularized policy writes that reward as \(\beta \log(\pi / \pi_{\mathrm{ref}})\), plus a constant that depends only on \(x\).
  • Set the model’s preference probability equal to the vote share \(\alpha\). The prompt constant cancels, and the reference odds remain.

Theorem 3.1 · DPO

Proof, from the classification loss

  1. The optimal KL-regularized reward is \( r(x,y) = \beta \log \frac{\pi_r(y \mid x)}{\pi_{\mathrm{ref}}(y \mid x)} + \beta \log Z(x) \).
  2. Under Bradley-Terry, \( Z(x) \) cancels and
    \[ \pi_r(y_w \succ y_l \mid x) = \sigma\!\left( \beta \log \frac{\pi_r(y_w \mid x)}{\pi_{\mathrm{ref}}(y_w \mid x)} - \beta \log \frac{\pi_r(y_l \mid x)}{\pi_{\mathrm{ref}}(y_l \mid x)} \right). \]
  3. DPO’s maximum likelihood sets this probability equal to \(\alpha(x, y_w, y_l)\).
  4. Rearrange, take a logarithm, and divide by \(\beta\):
    \[ \frac{1}{\beta}\log\frac{1-\alpha}{\alpha} = \log \frac{\pi^\star(y_l \mid x)\,\pi_{\mathrm{ref}}(y_w \mid x)}{\pi_{\mathrm{ref}}(y_l \mid x)\,\pi^\star(y_w \mid x)}. \]
  5. Exponentiate and invert the ratio. That is the displayed identity.

Theorem 3.1 · RLHF

The same ratio from the closed form

  1. The KL-regularized optimum is \( \pi^\star(y \mid x) \propto \pi_{\mathrm{ref}}(y \mid x) \exp(r_\phi(x,y)/\beta) \).
  2. The ratio of two completions is
    \[ \frac{\pi^\star(y_w \mid x)}{\pi^\star(y_l \mid x)} = \frac{\pi_{\mathrm{ref}}(y_w \mid x)}{\pi_{\mathrm{ref}}(y_l \mid x)} \exp\!\big((r_\phi(x,y_w) - r_\phi(x,y_l))/\beta\big). \]
  3. Bradley-Terry says \( \exp(r_\phi(x,y_w) - r_\phi(x,y_l)) = \alpha / (1-\alpha) \).
  4. Raise that identity to \(1/\beta\). The reference odds are unchanged.

Corollary 3.3

Idealized accuracy is that ratio, counted

\[ \mathcal{R}^\star = \mathbb{E}\left[ 1\!\left[ \frac{\pi_{\mathrm{ref}}(y_w \mid x)}{\pi_{\mathrm{ref}}(y_l \mid x)} \left(\frac{\alpha}{1-\alpha}\right)^{1/\beta} > 1 \right] \right]. \]

Intuition

  • A pair is ranked correctly exactly when the model ratio exceeds 1.
  • Theorem 3.1 already gives that ratio at the optimum, so there is nothing left to train.

Proof

  1. By Definition 2.3, \(\mathcal{R}(x,y_w,y_l)=1\) if and only if \(\pi(y_w \mid x)/\pi(y_l \mid x) > 1\).
  2. Substitute the ratio from Theorem 3.1.
  3. Average the indicator over the dataset.
  4. If every rater agrees, replace \(\alpha=1\) by \(1-0.001\). The paper evaluates \(\beta \in \{0.01, 0.1, 1, 5, 10\}\) and reports min, median, and max.

Proposition 2.6

The easy case needs a reference that is already right

Proposition 2.6

If \(\pi_{\mathrm{ref}}(y_w \mid x) \ge \pi_{\mathrm{ref}}(y_l \mid x)\) and the DPO loss on that pair is at most \(0.6\), then \(\mathcal{R}=1\).

Intuition

  • A loss of \(0.6\) is already past the point where the sigmoid is \(1/2\).
  • So the update boosts \(y_w\) at least as much as \(y_l\), relative to the reference.
  • If the reference was already right, the model stays right. Real references miss most pairs, so this hypothesis rarely holds.

Proposition 2.6

Proof

  1. Write \( a_x = \log \frac{\pi_\theta(y_w \mid x)}{\pi_{\mathrm{ref}}(y_w \mid x)} \) and \( b_x \) the same way for \(y_l\).
  2. The loss is \( -\log \sigma(\beta(a_x - b_x)) \). The hypothesis says this is at most \(0.6\).
  3. Exponentiate: \( \sigma(\beta(a_x - b_x)) \ge e^{-0.6} \).
  4. \( e^{-0.6} > 1/2 = \sigma(0) \), and \(\sigma\) is increasing, so \( a_x \ge b_x \).
  5. Therefore
    \[ \frac{\pi_\theta(y_w \mid x)}{\pi_\theta(y_l \mid x)} \ge \frac{\pi_{\mathrm{ref}}(y_w \mid x)}{\pi_{\mathrm{ref}}(y_l \mid x)} \ge 1. \]
  6. Definition 2.3 gives \(\mathcal{R}(x, y_w, y_l) = 1\).

Theorem 4.1

A wrong reference sets a tiny loss ceiling

\[ c = \log \frac{\pi_{\mathrm{ref}}(y_l \mid x)}{\pi_{\mathrm{ref}}(y_w \mid x)}. \]

Theorem 4.1

\(\mathcal{R}=1\) if and only if the DPO loss on that pair is at most \(-\log \sigma(\beta c)\).

Intuition

  • The loss is a sigmoid of the model log-ratio, shifted by the reference’s mistake \(c\).
  • The ranking flips only when the model log-ratio crosses 0.
  • If the reference prefers the loser, \(c>0\), and the loss has to get extremely small before that crossing happens. A long answer sums a small per-token tilt into a large \(c\).

Theorem 4.1

Proof

The loss decomposes as

\[ \mathcal{L}_{\mathrm{DPO}} = -\log \sigma\!\left( \beta \log \frac{\pi_\theta(y_w \mid x)}{\pi_\theta(y_l \mid x)} + \beta c \right). \]

If the loss is below the ceiling, the ranking is correct

  1. Assume \( \mathcal{L}_{\mathrm{DPO}} \le -\log \sigma(\beta c) \).
  2. \(\log\) and \(\sigma\) are increasing, and the leading minus sign reverses the inequality, so \( \beta \log \frac{\pi_\theta(y_w)}{\pi_\theta(y_l)} + \beta c \ge \beta c \).
  3. Cancel \(\beta c\). The model log-ratio is at least 0, so \(\pi_\theta(y_w \mid x) \ge \pi_\theta(y_l \mid x)\).

If the ranking is correct, the loss is below the ceiling

  1. Assume \(\mathcal{R}=1\), so \( \log \frac{\pi_\theta(y_w)}{\pi_\theta(y_l)} \ge 0 \).
  2. Add \(c\), multiply by \(\beta\), and apply \(\sigma\) and then \(\log\).
  3. Negate both sides. That is \( \mathcal{L}_{\mathrm{DPO}} \le -\log \sigma(\beta c) \).

From the authors’ talk

Where do we go from here?

  • Check both offline and online metrics during training.
  • Reconsider KL divergence as the regularizer.
  • Reduce reliance on a poorly aligned reference, or start from a stronger one.
  • Use a target margin, and stop rewarding an ever-wider margin.
  • Refresh the data with on-policy samples sooner than the usual schedule.

Takeaways

What to keep

  • The objective can say one thing while the checkpoint does another. Behavior at the optimum is not behavior in the middle of training.
  • A good ranker is not the same object as a good generator.
  • A split of the data, pair by pair, tells you more than the average loss.
  • These methods are sensitive to the gap between the dataset and the policy you actually sample from.
